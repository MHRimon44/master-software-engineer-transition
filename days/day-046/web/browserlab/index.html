    5. Security checklist

    • Never store production credentials or bearer tokens in this demo.
    • JavaScript-readable storage is exposed to malicious scripts if XSS occurs.
    • HttpOnly cookies cannot be read through document.cookie.
    • SameSite mitigates some CSRF cases; CSRF protections may still be required.
    • CORS is a browser read-access policy, not authentication or server authorization.
    • Cross-origin credentials require deliberate cookie attributes and server CORS configuration.
